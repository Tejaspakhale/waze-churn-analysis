# Data

The raw dataset is not stored in this repository because of its size.

1. Go to https://www.kaggle.com/datasets/mostafamohammednouh/waze-synthetic-user-churn-data
2. Download the file (a free Kaggle account is required)
3. Save it in this folder as `waze_dataset.csv`.

Dataset: 14,999 rows, 13 columns. Target column: `label` (1 = churned, 0 = retained).
